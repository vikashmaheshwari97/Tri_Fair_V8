Recover validation without retraining

Job 2839279 completed all five Bios methods. Job 2839280 stopped before Python evaluation because Lmod could not resolve python-venv/1.0. This is a job-startup dependency failure, separate from the earlier batch-order disagreement. The mandatory module load was retained in the previous job script and caused this failure.

The new job still loads the same Python base module and activates the existing project venv, but no longer requires the Spack python-venv module. It checks that Python actually belongs to that venv and is supported. All existing source, package, model-config, split and stability-proof checks remain active.

No file under src/ or scripts/ and no existing recovery launcher is replaced. The source and launcher hashes checked by the passing stability proof therefore remain unchanged. The change is recorded in UPGRADE_V88_MODULE_RECOVERY.json.
